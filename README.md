# Arkitect Toolbelt

Arkitect Toolbelt takes the busywork out of ARK: Survival Ascended: an auto clicker, one-key inventory drops, Magic F transfers and tame leveling, and helpers for renaming, PINs, eggs, baby feeding, and turrets.

## Download

Download `ArkitectToolbelt.exe` from the [latest release](https://github.com/MetricsGaming/Arkitect-Toolbelt-Release/releases/latest).

Windows may warn that the app is from an unknown publisher. To run it, click **More info**, then **Run anyway**.

## Requirements

- Windows 10 or 11
- ARK: Survival Ascended, in **Fullscreen Windowed** on your main screen, or on GeForce NOW
- A 16:9 screen, such as 1920x1080 or 2560x1440

## Get started

1. Run `ArkitectToolbelt.exe`.
2. Pick what you want on each page: **Clicker**, **Drop**, **Magic F**, and **Tools**.
3. Switch to ARK and use the keys below.

The keys that act on ARK only work while ARK is the window in front.

| Key | Action |
| --- | --- |
| **F5** | Start or stop the clicker. **Ctrl+Shift+F5** picks the next action. |
| **F4** | Run the drop mode on what you're looking at. **Ctrl+Shift+F4** picks the next mode. |
| **F8** | Turn Magic F on or off. **Ctrl+Shift+F8** picks the next mode. |
| **F9** | Turn the GeForce NOW background clicker on or off |
| **F1** | Take everything from the open inventory |
| **F2** | Give everything in your inventory |
| **F3** | Drop everything in your inventory |
| **Right Ctrl** | Walk forward until you press it again |
| **Caps Lock** | Rename the turret you're looking at, with **Turret rename** on |
| **F10** | Reload the app |
| **F12** | Exit |

If the inventory checks don't react, try **Pixel color** and **Gamma** on the **Settings** page.

## Updates

Arkitect Toolbelt checks for a new version each time it starts. When there is one, it asks whether to update, then downloads it, checks that the download is intact, and restarts. If you choose not to update yet, click **Update to vX** in the bottom corner of the window when you're ready.

## Your settings

The first time Arkitect Toolbelt runs, it creates `toolbelt.ini` next to the exe, with every setting at its default and a note on what each one does. After that, it saves your changes as you use the app, so you don't need to edit the file.

The file includes your Auto PIN code, so don't share it.

## Help

For questions or problems, message **Arkitect.dev** on Discord. The **About** page in Arkitect Toolbelt has a button that copies the name.
